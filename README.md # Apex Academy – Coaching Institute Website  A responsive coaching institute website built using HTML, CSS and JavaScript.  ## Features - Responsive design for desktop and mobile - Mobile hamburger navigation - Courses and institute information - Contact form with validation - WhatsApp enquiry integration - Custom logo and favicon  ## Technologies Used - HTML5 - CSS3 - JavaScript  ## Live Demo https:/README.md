
# Apex Academy – Coaching Institute Website

A responsive coaching institute website built using HTML, CSS and JavaScript.

## Features
- Responsive design for desktop and mobile
- Mobile hamburger navigation
- Courses and institute information
- Contact form with validation
- WhatsApp enquiry integration
- Custom logo and favicon

## Technologies Used
- HTML5
- CSS3
- JavaScript
